# Getting Started Guide

Quick start guide for new HatoFit users.

**Audience**: New Users  
**Last Updated**: February 2026

---

## Quick Start (5 Minutes)

### Step 1: Download & Install

| Platform | Store | Link |
|----------|-------|------|
| iOS | App Store | [Download on App Store] |
| Android | Play Store | [Get it on Google Play] |

### Step 2: Create Account

1. Open HatoFit app
2. Tap "Create Account"
3. Choose sign-up method:
   - **Email**: Enter email and password
   - **Google**: Tap "Continue with Google"
4. Accept Terms of Service
5. Create your profile

### Step 3: Set Up Profile

| Field | Description |
|-------|-------------|
| Name | Display name |
| Date of Birth | For HR zone calculations |
| Gender | For calorie calculations |
| Height | For BMI calculation |
| Weight | For calorie calculations |

### Step 4: Connect Heart Rate Monitor (Optional)

1. Tap "Devices" tab
2. Tap "+ Add Device"
3. Turn on your Polar device
4. Select device from list
5. Follow pairing instructions

---

## First Workout

### Starting Your First Workout

1. Go to **Workouts** tab
2. Browse exercise library
3. Select an exercise
4. Tap **Start**
5. Follow video instructions
