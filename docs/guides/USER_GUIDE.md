## Account Management

**Options:**
- Email registration
- Google Sign-In

**Information Required:**
- Email address
- Password (8+ characters)
- Name
- Date of birth
- Gender

**Access**: Settings → Profile

**Available Actions:**
- Update profile photo
- Edit personal information
- Update metrics (height, weight)

## Workouts

### Finding Workouts

1. **Browse Library**: Home → Workouts
2. **Filter by**:
   - Company
   - Difficulty
   - Category
3. **Search**: Use search bar

### Starting a Workout

1. Select exercise from library
2. Review exercise details
3. Tap **Start**
4. Follow video instructions
5. Track your progress

### Workout Features

| Feature | Description |
|---------|-------------|
| Video Playback | HD exercise demonstrations |
| Timer | Built-in countdown |
| Rest Periods | Auto-timed rest between sets |
| Notes | Exercise-specific tips |

## Heart Rate Monitoring

### Supported Devices

| Device | Type | Features |
|--------|------|----------|
| Polar H10 | Chest strap | HR, ECG, ACC |
| Polar H9 | Chest strap | HR only |
| Polar OH1 | Armband | HR, PPG |

### Connecting a Device

1. Enable Bluetooth on phone
2. Open HatoFit → Devices tab
3. Tap "+ Add Device"
4. Select your device
5. Confirm pairing

### Heart Rate Zones

| Zone | Color | Effort |
|------|-------|--------|
| Resting | Gray | Warm-up |
| Fat Burn | Blue | Light |
| Cardio | Green | Moderate |
| Peak | Orange | Hard |
| VO2 Max | Red | Maximum |

## Tips & Best Practices

### Getting Accurate Heart Rate

1. Moisten electrode area (Polar H10/H9)
2. Secure device snugly
3. Stay within 10 meters of phone
4. Avoid interference from other devices

### Maximizing Workout Benefits

1. Complete all exercises in sequence
2. Track heart rate for accurate calories
3. Review progress regularly
4. Set achievable goals
