# Workout Guide

How to effectively use HatoFit's workout tracking features.

**Audience**: Fitness Users  
**Last Updated**: February 2026

---

## Finding Workouts

### Browse Library

1. Open **Workouts** tab
2. Scroll through categories
3. Use filters to narrow down

### Filter Options

| Filter | Options |
|---------|---------|
| Company | FitPro, CoreFit, etc. |
| Difficulty | Beginner, Intermediate, Advanced |
| Category | Cardio, Strength, Flexibility |

### Search

Use the search bar to find specific exercises.

---

## Starting a Workout

### Before You Begin

1. Ensure phone is charged (50%+)
2. Connect heart rate monitor (optional)
3. Find comfortable space
4. Have water nearby

### Workout Flow

1. **Select Exercise** → Tap exercise card
2. **Review** → Read instructions
3. **Start** → Tap play button
4. **Follow Along** → Video demonstration
5. **Complete** → Finish all sets

## Workout Tips

### For Beginners

1. Start with beginner workouts
2. Focus on form over speed
3. Use lighter weights initially
4. Take rest periods seriously

### For Intermediate/Advanced

1. Increase intensity gradually
2. Track progressive overload
3. Use heart rate zones
4. Mix workout types

### Maximizing Results

| Goal | Approach |
|------|----------|
| Weight Loss | HIIT + cardio focus |
| Muscle Gain | Strength + progressive overload |
| Endurance | Longer sessions, lower intensity |
| General Fitness | Balanced mix |

## Common Questions

### "Video not loading"
- Check internet connection
- Try lower quality
- Restart app

### "Timer not working"
- Check volume is up
- Ensure notifications enabled
- Restart workout

### "Can't skip exercises"
- Set order must be followed
- Complete or skip via menu

---

## Workout Safety

### Before Starting

- Consult physician if needed
- Warm up properly
- Check equipment safety

### During Workout

- Stop if feeling pain
- Stay hydrated
- Use proper form

### After Workout

- Cool down stretches
- Log final stats
- Refuel with nutrition
